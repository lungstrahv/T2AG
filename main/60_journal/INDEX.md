# Journal 总索引

## 说明

本目录保存跨课程、跨实践、非故障类的重要事件、决策与待办。它是回看层，不是真相源。

默认不会自动写入；只有用户明确要求"记入 journal / 保存这段 / 这段很重要"时才保存。

月度索引（`YYYY-MM.md`）与总索引（`INDEX.md`）本身也是 journal 文件，随新内容加入持续更新。

## 命名规则

```text
YYYY-MM-DD-<主题关键词>.md    # 单篇 journal
YYYY-MM.md                    # 月度索引/报告
INDEX.md                      # 总索引
```

## 更新约定

- 新增 journal 时同步更新当月 `YYYY-MM.md`。
- 新增月度报告时同步更新本总索引。
- 单篇 journal 状态可选：进行中 / 待验证 / 已完成 / 已归档。
