## 什么是 R

R = 弹性执行绑定。与 G（Group，刚性课程组）平级。

- G/R 表示执行约束（刚性/弹性），不表示通识/专业、必修/选修等内容类别
- R 只允许绑定 Project 或 Praxis CourseRun
- Mastery 只能进入 G
- R 本身没有课程成功标准；验收方式由绑定的 CourseRun 类型决定

## R 允许的课程类型

| 课程类型 | 验收方式 |
|---|---|
| Project | 绑定验证模式 A/B/B-K |
| Praxis | 真实行动 + 外部反馈 |

**Mastery 不得进入 R。**
