# 外部学习资料共享索引（external_resources.md）

> 位置：`30_courses/_shared/`。只登记跨课程可复用的在线资源和确需离线保存的共享文件。
> 详细分类、落位、登记字段和唯一性规则见 `main/50_playbook/book_management.md`。
> 同一 URL 或本地文件只登记一次；课程 README 只引用资源 ID 和用途。

## 登记表

| 资源 ID | 名称 | 类型 | URL/本地路径 | 适用课程 | 适用知识点 | 用途 | 使用方式 | 来源与许可 | 最后核验日期 |
|---|---|---|---|---|---|---|---|---|---|
| ER001 | 示例公开课程（首次使用时替换本行） | 公开课 | `https://example.com/course` | COURSE001, COURSE002 | 待登记 | 辅助解释 | 在线读取 | 发布者公开页面；许可待核验 | YYYY-MM-DD |
