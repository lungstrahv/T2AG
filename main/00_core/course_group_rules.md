# 课程识别与课程组规则（course_group_rules.md）—— 放 00_core/，宪法附件

> 起因：S002 档案「当前课程」与课程组成员表冲突（IV1001 planned 是否算"当前"无法裁决）。
> 本文件一次性解决课程识别的引用混乱，并固化课程组的运行规则。
> 与 t2ag.md 宪法冲突时以宪法为准；本文件条款由 doctor 强制。

## 一、课程生命周期（状态枚举，写入各 course_status 头部）

```
planned（预划，只存在于 plan_v4 预划表或组文件，可有档案骨架）
  → active（进行中：当且仅当被"当前课程组"成员表收录）
  → paused（中断：曾 active，本组未收录且未完成——必须写中断原因与恢复条件）
  → archived（完成或废止：写结课评语）
```

**判据：一门课是否"当前"，唯一由课程组成员表决定。** course_status 只知道"学到哪"，
不裁决"是否现役"——这两个问题分属课程层与组层，混答即违规。

## 二、课程识别的引用纪律（本次事故的修法）

1. **权威链延长一环**：`当前课程组 = memory 指针（唯一真相源）→ 组文件成员表 = 当前课程清单（唯一真相源）`
   - memory 指针的物理位置：`t2ag_memory.md`「当前状态指针」节里的一行 `**当前课程组**:G01`
   - 换组仪式第 3 步是它**唯一的写入点**；其余任何 .md 不得反向写入
2. **全库禁止枚举式课程清单**：学生档案、course_info 备注、任何 .md 不得手写"当前课程：A、B、C"。
   需要引用时只写指针，且**不得硬编码组代码**：
   - ✅ `当前课程组：见 memory 指针（成员见对应组文件）`
   - ❌ `当前课程组：G01` （组代码副本，换组即腐烂）
   - ✅ `当前课程：IV1001（见组文件）`（单课引用带指针，合法）
3. course_info 课程列表增加「状态」列，取值即第一节枚举，结课/换组仪式时同步。
   - **性质**：它是手抄副本，但进了权威链的**合法缓存名单**——只在结课/换组仪式刷新、doctor 校验其与真相源一致。
   - **合法缓存与野生副本的区别**：从来不是抄没抄，而是有没有**登记的刷新时机和校验人**。
4. **定律入档**（problemlog 永久条目）：凡手写两遍的信息必然不一致——进度、版本号、课程清单已三次验证。解法恒为：删副本，留指针。

## 三、课程组的双线性质（设计意图，供组建档时参考）

每个组建议包含两类成员，配比随阶段流动：
- **项目线**（造外部的东西）：验收在世界一侧——能运行、有产出、可交付（如 PY1001+P001）
- **语言线**（造内部的结构）：验收以卷面考核为主，过程指标为辅；题目只选编真题，不由 AI 生成。正文见 `main/50_playbook/exam_protocol.md`。

语言线默认期末权重：卷面 70%，过程指标 30%。卷面考核必须来自隔离的考核池；过程指标可含 mistake_bank 复发率、反例即答、盲判等。
组文件成员表加一列「线别：项目/语言」，期末评估分别按各自标准验收，不得互相折算。

### 项目线验证条款

> 项目线课程每个里程碑必须绑定验证模式（A/B，建组或 M 启动前登记，大调整窗口可改未启动 M），任何模式必须满足三机制：外部真相源、独立性测量、失败留痕。
> 操作细则见 `50_playbook/project_verification.md`。

## 四、刚性与流动的边界（组运行规则）

> **执行参数化原则**：协议层只规定必须存在的机制，不固定参数值。周期结构、复盘位置、小调整频率、大调整频率等参数，在建组仪式或学生执行参数中生成；未讨论前使用 S001 模板默认值。
>
> **S001 模板默认调整规则**：3-1-3 周期；每周两次小调整（每次至多一处运行参数），每四周一次大调整窗口。

| 维度 | 规则 |
|---|---|
| 周期 | **刚性**。执行参数必须写明周期容器；期末节点不后移，滑期进缓冲或大调整窗口消化 |
| 频率红线 | **刚性**。破线周期计入期末评估，连续两周期破线触发紧急复盘 |
| 仪式 | **刚性**。复盘、调整、卷面考核、组级评估、结组仪式不可省略；具体频率由学生执行参数决定 |
| 范围 | **弹性**。可砍内容进下一组，砍必留痕（course_status 记"未完成部分及去向"） |
| 配方 | **组间流动，组内冻结**。成员增删、换教材、课程状态转正只在结组仪式发生；组内只走小调整/大调整分级通道 |

> **调整分级边界**：小调整 = 运行参数；大调整 = 范围级；配方级 = 组成员/教材/课程状态，只在结组仪式发生。
> 机械判断：凡是需要动组文件成员表或 course_status 状态字段的调整，至少是大调整；凡是要加减课程或换教材，就是配方级。
>
> 原理：deadline 固定、范围弹性 = 完成率的全部秘密；组内换配方 = 学习版的"阴跌中失耐心离场"。
> 第一个完整闭环的叙事价值 > 组内任何具体内容——完成本身是对旧病史的证伪。

## 五、换组仪式（group_transition，入 50_playbook）

触发：期末评估完成时，且仅此时。五步：
1. 旧组状态 archived，期末评估表为结组档案
2. 新组**此刻才建档**（预划表禁止提前建档案——防僵尸文件）：成员表、线别、预算、本期目标
3. 改 memory 指针（换组的唯一写入点）
4. 成员课程状态流转：延续课 active 留任新组（course_status 不动，课的进度与组无关）；
   完结课 archived；落选课 paused+写恢复条件
5. 跑 doctor 验证 → changelog 记录

## 六、doctor 增检四条

| 检查 | 级别 |
|---|---|
| memory 指针指向的组文件不存在或状态非 active | FAIL |
| 全库 active 组数量 ≠ 1 | FAIL |
| active 课程未出现在当前组成员表 / 成员表课程状态非 active | FAIL |
| 权威链外的 .md 出现枚举式课程清单 | WARN |
| 考核池卷的题号引用出现在 lesson/practice 文件 | FAIL |
| `papers/` 下有卷夹但 index 未登记，或 meta 缺列/缺解答页码 | WARN |

> 第四条实现口径：
> - **只抓枚举，单课引用合法**：匹配"当前课程"后同一行出现 **≥2 个课程代码**模式（`[A-Z]{2,}\d{3,}` 计数），单代码不触发。
> - **白名单**：组文件自身（真相源本源）和 plan_v4 预划表（无效力假设）豁免，不被此条打扰。
> - 单课引用如 `当前课程：IV1001（见组文件）`不违规；若该课不在当前组成员表内，doctor 顺手送一条 WARN "引用过时"。
