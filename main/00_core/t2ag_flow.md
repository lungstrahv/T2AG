# T2AG 功能流程图（00_core/t2ag_flow.md）

> 本文件回答"系统跑起来是什么样"，与 t2ag.md（规则）、feedback_map（反馈分层）、
> pattern_retire_loop（复利模式）互补。纯 ASCII，任何 agent/编辑器可读。
> 规则与本图冲突时以 t2ag.md 为准，并修本图。

## 图 1 · 一次教学会话的完整生命周期（主流程）

```
学生:"继续学 MATH1607H"
        │
        ▼
┌─ 开课阶段 ────────────────────────────────────────┐
│ 1 跑 doctor ──FAIL──→ 以 course_status 为准修复,   │
│      │ 全绿           口头核对后才继续              │
│      ▼                                            │
│ 2 读 memory:上次课摘要→状态指针→行动前检查9步      │
│      ▼                                            │
│ 3 按需加载:course_status(真相源)/overlay/emo最近1-2条│
│      ▼                                            │
│ 4 复测:mistake_bank 抽2-3条到期旧错,变形提问        │
│   (无到期条目则跳过,结果暂记不写盘)                 │
└──────┬────────────────────────────────────────────┘
       ▼
┌─ 正课循环(重复至结束信号) ─────────────────────────┐
│ temppage读教材原文→讲解→学生复述+举正反例           │
│   ├─ 疑问 ──→ 必答;答不动→lesson"暂存疑问"待销账    │
│   ├─ 习题 ──→ 四级梯子(自想10min→提示→查讲义→全讲) │
│   │            第4级触发→该题标记待入mistake_bank   │
│   └─ 情绪触发词 ──→ 标记待写状态档(红线:不降标准)   │
└──────┬────────────────────────────────────────────┘
       ▼ 学生:"下课"/内容自然结束
┌─ 结课仪式(session_close 八步,不写完不算下课) ───────┐
│ ①写真相源course_status(进度+精确停顿点+时长)        │
│ ②收割错误→mistake_bank(新增权重3;复测✓-1/✗+1)      │
│ ③学生状态→students档案(只写观察与原话)              │
│ ④刷新memory(摘要五问+指针+速览+最近动态,查节预算)   │
│ ⑤刷新course_info进度列   ⑥temppage窗口处理          │
│ ⑦课后提炼(可固化playbook?) ⑧输出"写入确认"块给学生  │
└──────┬────────────────────────────────────────────┘
       ▼
     下课(中断兜底:仪式没走完→下次开课doctor必报不一致)
```

## 图 2 · 权威链数据流（谁是源，谁是缓存，何时流动）

```
                 结课仪式①(唯一写入口)
                        │
                        ▼
        ┌── course_status.md(真相源/每课一份) ──┐
        │ 只在结课时写;冲突时一切以它为准        │
        └──────┬──────────────────┬─────────────┘
        仪式④刷新            仪式⑤刷新
               ▼                  ▼
   memory指针/速览(缓存)   course_info进度列(缓存)
               │
        开课时被读取 ←──── doctor 校验三级一致
                            (不一致=上次仪式未走完)

  旁路数据流: lesson错误──仪式②──→mistake_bank──开课④──→复测
             工具故障────随时────→problemlog──→修playbook/工具
             情绪触发词──仪式③──→students档案──开课③──→调节奏语气
```

## 图 3 · 周期性回路（会话之外的心跳）

```
每次会话:  开课复测 ←→ 结课收割          (复利回路模式,日频)
每周日1h:  G01五问复盘→"下周唯一调整"    (组文件,防方案漂移)
每月末+20min: 交易月复盘(P002)→归因标签统计→改交易系统v1
每月:      memory"长期事实"节淘汰(三周未用→下沉留痕)
期中/期末: 课程组评估(第7/14周)──期末──→结组仪式→归档G01→建G02
里程碑末:  环境重建验证(删.venv重装跑通)
版本变更:  任何规则修改→changelog→memory"最近动态"同步
```

## 图 4 · 角色视角速查

```
学生只需要说: "继续学X" / 提问 / "下课" / (可选)抽查写入确认块
agent负责:   图1全流程 + 图3中除"学生评价"外的一切
doctor负责:  图2一致性 + memory节预算 + 断链 + venv/env + 版本号
文件负责:    记住一切——agent可以换,图1-3不变
```
