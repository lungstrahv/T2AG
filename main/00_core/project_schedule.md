## 五、同步纪律

- 主仓结构性变更（新 playbook、模板改动、doctor 新检查）→ changelog 记版本号当天，同步进 skeleton 仓并打相同版本 tag
- doctor 软检查：主仓版本号与 skeleton 仓最新 tag 不一致 → WARN
- **手写两遍必不一致**——skeleton 不同步就会退化成化石
