# outbox

This directory holds component-change directives sent from the local instance to
the cloud. A formal directive is named `CD-YYYYMMDD-NNNN.md`.

An empty outbox is the valid initial Skeleton state. This README keeps the
`cloud/outbox/` protocol path present in Git, GitHub ZIP downloads, and clones. It
is not a directive and must never be registered as evidence that anything was sent.
