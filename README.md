# T2AG — vibe learning 教学系统（by T2AC）

> 一个因懒惰而生的 AI 教学辅导系统。本目录是**从零开始的空白骨架**，
> 不含任何真实师生数据，可直接用于初始化一个新的 T2AG 实例。

## 这是什么

T2AG（by T2AC）通过持久化的 Markdown 文件（案例、师生信息、课程状态、问题日志）
让 AI agent 在长期辅导中记住学生、记住进度、记住踩过的坑。
**没有运行时**，所有状态靠文件约定管理。

- 版本：`0.0.05`（宪法版；采用数字前缀命名规范）
- **再生用种子**：本 `T2AC_skeleton` 骨架整体（解压即可再生系统）
- **宪法与结构清单**：`main/t2ac.md`（不再是种子，只在接管/仲裁时完整阅读）
- 设计理念：不绑定特定 AI 工具（Kimi / Claude Code / Cursor / Hermes / TRAE 均可）

## 快速开始（三步）

### 第一步：解压 skeleton
把 `T2AC_skeleton` 整个文件夹复制或解压到你的工作目录，重命名为你想要的项目名。

### 第二步：在 AI 环境中打开
用 TRAE / Cursor / Claude Code / Kimi 打开这个文件夹。

- TRAE：直接打开文件夹，TRAE 会自动读取 `AGENTS.md` 识别 t2ac 系统
- Cursor：打开文件夹后，`.cursorrules` 若缺则 agent 会自动生成
- Claude Code：打开文件夹后，`CLAUDE.md` 若缺则 agent 会自动生成
- 其他环境：发送 `t2ac` 或「读取 t2ac.md」手动触发

### 第三步：发送启动指令
在对话中发送 `t2ac` 或「读取 t2ac.md」。

agent 会依次问你：
1. 你的名字或昵称
2. 你要学什么课程（可多门）
3. 每门课的教材是什么
4. 你现在学到哪了
5. 有什么学习偏好

确认后 agent 会自动创建你的档案和课程文件夹，然后展示欢迎信息。

> **之后每次上课**：发送「继续学 [课程代码]」即可恢复进度开始上课。
> **首次启动后**：日常开课不再需要发 `t2ac`，直接说课程名就行。

> **注意**：本骨架中 `S001/`、`T001.md` 是占位模板。实际学生从 `S002` 起编号。
> 首次启动不得携带任何其他实例的数据，一切从询问用户开始。

## 命名规范（数字前缀方案）

`main/` 下系统目录用**两位数字前缀**编码阅读顺序与依赖方向：

| 前缀 | 目录 | 作用 |
|---|---|---|
| 00 | `00_core/` | 宪法、记忆、变更/问题日志（最先读） |
| 10 | `10_case/` | 师生信息、课程配置 |
| 20 | `20_groups/` | 课程组执行窗口 |
| 30 | `30_courses/` | 各课程文件夹（`代码_名称`） |
| 40 | `40_practices/` | 实践项目 |
| 50 | `50_playbook/` | 可复用流程 |
| 60 | `60_journal/` | 可选回看层 |
| 70 | `70_tools/` | 脚本工具 |

规则：**下层可引用上层，反向引用由 doctor 警告**。数字段一眼可见依赖方向。
