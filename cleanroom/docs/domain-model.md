# Domain model

| Term | Meaning and owner |
|---|---|
| Student declaration | An attributed statement; missing facts stay missing. Preferences do not authorize future transitions. |
| Course | Owns completion semantics: Mastery, Project or Praxis. A Mastery learning mode is not a course type. |
| Activity | A stable namespaced Lesson, Exercise or explicitly new Adhoc object. Old classroom questions were not automatically standalone Adhoc objects. |
| Source page | Immutable source version, physical page index, printed label and verified content, with raw provenance. |
| Teaching block | A teacher's arrangement mapped to source excerpts and their roles; it does not rename the original textbook. |
| Scope / preparation / scan | Current selected material, advance preparation and actual session consumption. They are separate evidence. |
| Criterion / answer / judgment | Frozen basis, actual submission and attributed evaluation. History is not silently regraded. |
| Ticket | Single current-session permission bound to its target and content. Consumed or revoked permission remains history. |
| Cursor | The exact position, waiting gate, pending wording and next action. It is committed with the learning transition. |
| Checkpoint / completion | Arrival or understanding evidence versus a type-specific completion node; neither automatically closes the course. |
| Pending close | Complete presented review and proposed outcome, bound by digest to one activity and an actual student decision. |
| Reading record / Engagement | Low-governance reading intent, versus sustained real-world engagement with external governance. |
| Group / binding | A group owns membership, calendar and time budgets, plus its declared closing conditions. A binding retains a cross-course ritual and execution evidence without changing course progress or group budgets. |
| Thought / reflection / pattern | Learner wording, evidence-based reflection and a refutable hypothesis for future use. |
| Journal / projection | Durable authoritative transaction sequence versus replaceable derived views. |
| Access surface / execution host | Phone or desktop interface versus the host executing actions. Changing the interface does not create a new learning-state authority. |
| Independent exchange | An explicitly enabled compatibility path for evidence produced outside the authoritative instance; not the default mobile workflow. |
| Language rule / decision gate / program check | Guidance for semantic behavior, a condition for a transition, and executable verification of decidable facts. A gate and a program are complementary axes, not mutually exclusive rule categories. |
| Migration package | A frozen source snapshot, with byte evidence and explicit semantic mappings; it does not issue new permission. |

Changing these meanings requires a recorded decision and updated consumers. An index or flow diagram is a navigation aid, not a second rule body.
