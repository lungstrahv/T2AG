# 使用 T2AG

T2AG 帮助你把教材、讲解、练习、真实反馈和学习计划接起来。它既能直接讲解和举例，也能提问检查理解；具体怎么教由内容和你的反馈决定。它保存的是实际讲过、答过、确认过的内容，而不是从一次答对推断长期掌握。

## 认识你，开始学习

先说想学什么、希望怎样学。已有教材、基础、时间安排和偏好都可以补充，不必先填完一套问卷；没说的内容不会被猜成事实。选择中文或英文后，教师提出完整、可修改的方案，你确认后开始。

```text
你的目标、已有材料与偏好
↓
可修改的课程、教师与时间安排
↓
你确认具体方案
↓
建立课程，从第一项活动开始
```

Mastery 课程支持教材、目标或项目方式；Project 课程靠外部可复现里程碑验收；Praxis 课程保留真实行动、反馈与不确定性。

你可以先用低治理阅读记录探索一个问题，跨多本书继续读；以后再明确升级成课程。阅读记录和弹性绑定不自动占用课程组预算。

## 继续学习

告诉教师要继续哪门课。它会找回当前活动、停点、正在等待的原文、未闭疑问和下一步。处理维护或审查事务不会把你自动带进课堂；确有历史冲突时，只核对影响继续学习的部分。

教材课需本会话实际读取当前 Scope 中每页的合适证据。备课、历史扫描和哈希只能帮助定位材料，不能代替当前阅读。版式关键或未知的页需要整页图像；普通页可读取已核验全文。扫描完毕并不意味着已经讲过。

## 手机与电脑之间继续

手机连接同一台电脑上的任务时，继续使用同一份课程、教材和进度，不需要另外上传镜像或手动同步。短暂断线后，先核对上一条操作是否已保存，再继续原停点，避免重复计时或作答。

只有在无法访问这个实例的独立云端对话中学习，才需要明确启用兼容同步。断线不会自动新开一份课堂；换设备也不会自动获得推进下一步的许可。

## 课堂工作原理

```text
教材原件、位置、原有顺序与用途
↓
核验页内容，本会话实际读取
↓
教师拆分、合并、命名，保留与原文的对应
↓
讲解、举例、示范或提问
```

回答之后，教学反馈与保存状态分别说明：

```text
实际回答 + 判据 → 教师判断 → 及时反馈
原答 + 判断 + 停点 → 一次保存 → 回执
```

继续学习与后台整理各走自己的路径：

```text
感受与疑问 → 本次继续许可 → 下一块

已保存事实 → 恢复视图、时间统计、进度索引
相关变化 → 相关检查
导入、完整性故障、发行 → 全量检查
```

教师拟名必须注明属于教学安排，并关联教材原文及其用途。“以后讨论……”可以简短解释，但不能因教师拆出一块便变成教材在此要求展开的新章。

理解确认、感受反馈和下一块许可是不同决定。正确回答可以马上得到数学反馈；“已保存”只在收到持久提交回执后说。保存失败或结果未知会单独说明；投影更新失败也不能抹掉已经成功提交的进展。全量诊断不应被无差别塞进每次答题。

## 练习与考试

练习保留原题顺序、教师安排顺序、原始作答及图片、冻结判据和逐次批改。方向提示、指定资料和完整解答分别授权，不跨题继承；帮助暴露影响独立性评价，不变成学生的错误。教师新增补充题需要你选择，且不能挤进原教材题序冒充题源。

考试使用独立题库、适合性核对、隔离与冷却、冻结评分依据及考试台账。错题复测区分独立正确、提示后正确和污染；保留旧错题及根因。一次考试或课堂答对不会自行宣布习惯形成。

## 保存与结课

保存可以在任意停点发生，不会自动暂停或结束活动。恢复继续同一个问题、正文和确认门。

结课先展示完整复盘，说明已做、未做和结果。你可以自然地说“这节就到这里，剩下的以后再学”，教师据此关闭为未完成；不会把保存或答对当成结课。修订复盘后按新内容确认。拒绝结课可以继续当前活动；重新开启仍保留上次结束的记录。结束整门课程另作决定。

## 计划、复盘与治理

课程组拥有组合、时间安排和阈值，课程拥有自己的学习进度。一个时点只激活一个组；换组不会结束组外课程。未采纳建议保持候选或延期，只有存在实际落地引用才能记作采纳。

学生想法保留原话；反思与可检验模式回链证据，并在相关活动中消费。系统问题可复发、重开和追踪修法；规则须有可观察失败及实际消费者。文字约定与机器检查会明确区分。

## 数据迁移与恢复

迁移先导出冻结交换包，核对字节、身份、引用和导出期间的源变化，再导入全新的实例。原件保留。迁移结果会分别说明原件保全、语义转换和可恢复状态；未解析内容与冲突不会被包装成已完成。

旧票据、旧扫描、旧判断仍是历史，不能自动签发本会话许可。若迁移后任一侧继续产生记录，回滚必须先保全双方增量、确定共同状态并核对冲突，不能盲目切回导致新进展消失。

## 维护与交付

agent 可按相关对象变化选择检查；日志、对象版本与动作本身的必要前置在提交时执行。全量检查用于导入、完整性疑点和交付资格。派生视图可以重建，不能覆盖原始事实。

公开包只包含运行时和通用协议；个人实例、教材、私有附件和测量对话不进入公开包。Lite 是只读审查投影，OKF 默认只导出机制文书。发行候选、独立审查通过和正式发布是不同状态。
