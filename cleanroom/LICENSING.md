# License boundaries / 许可证边界

This cleanroom candidate retains T2AG's existing license split. It does not
change the licenses of earlier releases or of imported third-party material.

本候选沿用 T2AG 既定的代码／文书许可划分；不改变旧版或导入的第三方资料的许可。

| Files / 文件 | License / 许可 |
|---|---|
| `t2ag_next/*.py`, `tests/*.py`, executable scripts, JSON and TOML configuration | Apache License 2.0 — [LICENSE](LICENSE) |
| `README.md`, `AGENTS.md`, `docs/*.md`, guides and other prose | CC BY-SA 4.0 — [LICENSE-DOCS.md](LICENSE-DOCS.md) |

For a file mixing prose and code, its primary form determines the license of
that file. See [NOTICE](NOTICE) for attribution. Personal learning instances,
source books and third-party evidence are not included in the runtime package;
importing them does not grant a redistribution license.

混合代码与文字的文件按其主要形式归类；署名见 [NOTICE](NOTICE)。运行包不包含个人学习
实例、教材或第三方证据；导入资料不授予新的再分发许可。
